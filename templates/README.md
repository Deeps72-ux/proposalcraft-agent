# ProposalCraft Document Templates & Brand Assets

This directory contains corporate style configurations, theme definitions, and optional logo assets used by ProposalCraft's document rendering engines.

## Available Themes:
- **Executive Blue**: Slate 900 primary with Royal Blue 600 accents.
- **Modern Indigo**: Deep Indigo primary with Indigo 500 tech accents.
- **Emerald Consulting**: Deep Emerald primary with Mint Green accents.
